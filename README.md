# Learning Test Driven Development

## Overview
I built a Django app by obeying the testing [goat](https://www.obeythetestinggoat.com/). The testing goat taught 
me test driven development. I wanted to learn test driven development after reading Clean code, which mentioned TDD
more times than I can remember. I bought a new book, to explore and followed its 500 pages. This Django App is the result. 

The app creates to do lists. A list can set an owner and that owner can share its list. A user logs in 
with URLs. No passwords up in here! But its function is not the same as its purpose. 

I built this app to learn test driven development. Building the app taught me different types of testing. Functional
tests, contract tests, and collaboration tests. Plus it taught me different ways of testing, using mocks or no 
mocks.
